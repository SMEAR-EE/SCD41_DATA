# SCD41 Validation Study - Setup Guide

Quick setup for the sensor data processing pipeline.

## Prerequisites

- Python 3.10 or higher
- Git (for cloning the repository)
- ~500 MB disk space for dependencies

## Installation

### 1. Clone Repository (if not already done)

```bash
git clone <repository-url>
cd SCD41_DATA
```

### 2. Run Setup Script

```bash
./setup.sh
```

This will:
- ✓ Create Python virtual environment (`venv/`)
- ✓ Install all required packages
- ✓ Create output directory structure
- ✓ Verify project files are in place

**Setup takes ~2-3 minutes** (downloading packages).

### 3. Configure Sensors

Edit `config/sensors.yaml` to point to your data directories:

```yaml
sensors:
  - name: CO2_SCT1_2M
    input_dir: /path/to/your/data/CO2-SCT1-2M  # ← Update these paths
    ...
```

### 4. Activate Environment

```bash
source activate.sh
```

Or manually:
```bash
source venv/bin/activate
```

## Usage

### Option 1: Jupyter Notebook (Recommended)

```bash
source activate.sh
jupyter notebook
```

Open `process_data.ipynb` and run cells.

### Option 2: Command Line

```bash
source activate.sh
python -c "
from src.config import PipelineConfig
from src.pipeline import SensorPipeline

config = PipelineConfig.from_yaml('config/sensors.yaml')
pipeline = SensorPipeline(config)
pipeline.run_all(year=2024, month=9)
"
```

### Option 3: Python Script

```python
from src.config import PipelineConfig
from src.pipeline import SensorPipeline
from src.merger import merge_all_sensors

# Load config
config = PipelineConfig.from_yaml('config/sensors.yaml')

# Process sensors
pipeline = SensorPipeline(config)
pipeline.run_all(year=2024, month=9)

# Merge results
merged = merge_all_sensors(
    individual_dir=config.output_dir,
    sensor_names=[s.name for s in config.sensors]
)
```


## Troubleshooting

### "python3: command not found"
Install Python 3.10+ from [python.org](https://python.org)

### "Permission denied: ./setup.sh"
```bash
chmod +x setup.sh
./setup.sh
```

### "No module named 'src'"
Make sure you're running from the project root and venv is activated:
```bash
source activate.sh
python -c "import src; print('✓ Import works')"
```

### Package installation fails
Try updating pip first:
```bash
source venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt  # if you have one
```

## Deactivating Environment

When you're done:
```bash
deactivate
```

## Updating Dependencies

If you need to add packages later:
```bash
source activate.sh
pip install <package-name>
```

## Clean Reinstall

To start fresh:
```bash
rm -rf venv/
rm -rf output/
./setup.sh
```

This preserves your source code and data while rebuilding the environment.
