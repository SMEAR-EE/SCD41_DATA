## File Types Overview

| File Type | Format | Size (1 month) | Precision | Use Case |
|-----------|--------|----------------|-----------|----------|
| 10-minute CSV | CSV | ~2-5 MB | Full | Human-readable, universal compatibility |
| Monthly CSV | CSV | ~500 KB | Full | Per-month analysis |
| Monthly Parquet | Parquet (Snappy) | ~50-200 KB | Full | Efficient storage, fast reads |
| Uptime Log | CSV | ~5-20 KB | Full | Data quality monitoring |
| Merged CSV | CSV | ~20-50 MB | Full | Multi-sensor analysis |
| Merged Parquet | Parquet (Snappy) | ~2-5 MB | Full | Efficient multi-sensor storage |

## Per-Sensor Outputs

### 10-Minute Resampled CSV

**File naming:** `{sensor_name}_10min.csv`  
**Example:** `CO2_SCT1_2M_10min.csv`

**Description:** Primary output containing 10-minute aggregated measurements for a single sensor.

#### SCD41 Sensor Schema

| Column | Type | Units | Description | Example |
|--------|------|-------|-------------|---------|
| `timestamp` | datetime | ISO 8601 | Measurement timestamp (start of 10-min window) | `2024-09-01 12:00:00` |
| `co2_mean` | float | ppm | Mean CO2 concentration | `420.5` |
| `co2_std` | float | ppm | Standard deviation of CO2 within window | `2.3` |
| `co2_count` | int | - | Number of raw measurements in window | `10` |
| `co2_qc` | string | - | Quality control flag for CO2 | `OK` |
| `temp_mean` | float | °C | Mean temperature | `22.4` |
| `temp_std` | float | °C | Standard deviation of temperature | `0.5` |
| `temp_count` | int | - | Number of temperature measurements | `10` |
| `temp_qc` | string | - | Quality control flag for temperature | `OK` |
| `humidity_mean` | float | % | Mean relative humidity | `65.2` |
| `humidity_std` | float | % | Standard deviation of humidity | `1.8` |
| `humidity_count` | int | - | Number of humidity measurements | `10` |
| `humidity_qc` | string | - | Quality control flag for humidity | `OK` |

**Total columns:** 13

**Typical row count:**
- 1 day: 144 rows (24 hours × 6 intervals/hour)
- 1 month: ~4,320 rows (30 days × 144)

### Uptime Log CSV

**File naming:** `{sensor_name}_uptime.csv`  
**Example:** `CO2_SCT1_2M_uptime.csv`

**Description:** Daily uptime statistics tracking data availability and quality.

| Column | Type | Units | Description | Example |
|--------|------|-------|-------------|---------|
| `year` | int | - | Year | `2024` |
| `month` | int | - | Month (1-12) | `9` |
| `day` | int | - | Day (1-31) | `15` |
| `start` | datetime | ISO 8601 | First timestamp of day | `2024-09-15 00:00:12` |
| `end` | datetime | ISO 8601 | Last timestamp of day | `2024-09-15 23:59:48` |
| `uptime_ratio` | float | 0-1 | Time-based uptime ratio | `0.957` |
| `sample_ratio` | float | 0-1 | Sample count vs expected | `0.951` |
| `num_gaps` | int | - | Number of gaps > 2×interval | `3` |
| `max_gap_minutes` | float | minutes | Duration of longest gap | `120.5` |
| `detected_interval` | float | seconds | Median sampling interval | `60.2` |
| `total_samples` | int | - | Actual number of samples | `1370` |
| `expected_samples` | int | - | Expected number of samples | `1440` |
| `qc_co2_ok` | int | - | Count of CO2 measurements with OK flag | `1350` |
| `qc_co2_flagged` | int | - | Count of CO2 measurements flagged | `20` |
| `qc_temp_ok` | int | - | Count of temp measurements with OK flag | `1365` |
| `qc_temp_flagged` | int | - | Count of temp measurements flagged | `5` |
| ... | ... | ... | (Additional QC columns per variable) | ... |

**Total columns:** ~15-20 (varies by sensor variables)

**Typical row count:**
- 1 month: 30 rows (one per day)

---

### Monthly CSV

**File naming:** `{sensor_name}_{YYYY}_{MM}.csv`  
**Example:** `CO2_SCT1_2M_2024_09.csv`

**Description:** Subset of 10-minute resampled data for a specific month. Schema identical to 10-minute CSV above.

---

### Monthly Parquet

**File naming:** `{sensor_name}_{YYYY}_{MM}.parquet`  
**Example:** `CO2_SCT1_2M_2024_09.parquet`

**Description:** Compressed binary version of monthly CSV. Schema identical but with native data types:

- `timestamp`: `datetime64[ns]`
- `*_mean`, `*_std`: `float64`
- `*_count`: `int64`
- `*_qc`, `Fit_Flag`: `string` (or `category` for efficiency)

**Compression:** Snappy (fast read/write, ~10× smaller than CSV)

**Advantages:**
- 10× smaller file size
- Faster to read in Python/R
- Preserves exact data types
- Columnar storage (efficient for analytics)

## Merged Outputs

### Merged CSV Schema

**File naming:** `SMEAR_EE_CO2_merged.csv`

**Description:** Time-aligned dataset combining all sensors via OUTER JOIN.

#### Column Naming Convention

Columns are prefixed with lowercase sensor name:

```
{sensor_name}_{variable}_{statistic}
```

**Examples:**
- `co2_sct1_2m_co2_mean` - SCD41 2m sensor, CO2, mean
- `lgr_30m_CO2_dry_mean` - LGR 30m sensor, dry CO2, mean
- `co2_30m_a_co2_qc` - SCD41 30m sensor A, CO2 QC flag

#### Core Columns

| Column | Type | Units | Description |
|--------|------|-------|-------------|
| `timestamp` | datetime | ISO 8601 | Measurement timestamp |

#### Per-Sensor Columns (example: CO2_SCT1_2M)

| Column | Type | Units | Description |
|--------|------|-------|-------------|
| `co2_sct1_2m_co2_mean` | float | ppm | Mean CO2 |
| `co2_sct1_2m_co2_std` | float | ppm | CO2 std dev |
| `co2_sct1_2m_co2_count` | int | - | CO2 sample count |
| `co2_sct1_2m_co2_qc` | string | - | CO2 QC flag |
| `co2_sct1_2m_temp_mean` | float | °C | Mean temperature |
| `co2_sct1_2m_temp_std` | float | °C | Temp std dev |
| `co2_sct1_2m_temp_count` | int | - | Temp sample count |
| `co2_sct1_2m_temp_qc` | string | - | Temp QC flag |
| `co2_sct1_2m_humidity_mean` | float | % | Mean humidity |
| ... | ... | ... | ... |

#### LGR Sensor Columns (example: LGR_30M)

| Column | Type | Units | Description |
|--------|------|-------|-------------|
| `lgr_30m_CO2_dry_mean` | float | ppm | **Primary reference CO2** |
| `lgr_30m_CO2_dry_sd` | float | ppm | CO2 uncertainty |
| `lgr_30m_CO2_dry_count` | int | - | CO2 sample count |
| `lgr_30m_CH4_dry_mean` | float | ppm | Dry methane |
| `lgr_30m_H2O_ppm_mean` | float | ppm | Water vapor |
| `lgr_30m_GasP_torr_mean` | float | torr | Gas pressure |
| `lgr_30m_GasT_C_mean` | float | °C | Gas temperature |
| `lgr_30m_quality_mean` | float | - | Quality indicator |
| `lgr_30m_Fit_Flag` | string | - | Fit quality flag |
| ... | ... | ... | ... |

#### Cross-Sensor Statistics (30m Cluster)

Computed from 3 co-located SCD41 sensors at 30m height (A, B, C):

| Column | Type | Units | Description |
|--------|------|-------|-------------|
| `scd41_30m_cluster_co2_mean` | float | ppm | Mean CO2 across available 30m sensors |
| `scd41_30m_cluster_co2_std` | float | ppm | Std dev across available 30m sensors |
| `scd41_30m_cluster_co2_count` | int | - | Number of sensors reporting data |

**Note:** These are computed only from available data. If only 1 sensor has data, mean = that value, std = NaN.

#### Total Column Count

Typical merged dataset:
- 1 timestamp column
- ~15 columns × 5 sensors = 75 sensor columns
- 3 cluster statistic columns
- **Total: ~80 columns**

#### Missing Data Representation

- **NaN (Not a Number):** No data from sensor at this timestamp
- **Interpretation:** Missing data is EXPLICIT, not interpolated
- **Example:** If SCD41_A has no data at 12:00, `co2_30m_a_co2_mean` = NaN

### Merged Parquet Schema

**File naming:** `SMEAR_EE_CO2_{YYYY}_{MM}_merged.parquet`

**Description:** Compressed monthly merged dataset. Schema identical to merged CSV.

**Advantages:**
- ~10-20× smaller than CSV
- Faster column-wise queries
- Preserves data types exactly
- Efficient for large-scale analysis

## Quality Control Flags

### Flag Values

| Flag | Meaning | Action Required |
|------|---------|-----------------|
| `OK` | Measurement within expected range | None - data is valid |
| `BELOW_RANGE` | Value below minimum threshold | Check sensor calibration |
| `ABOVE_RANGE` | Value above maximum threshold | Check sensor calibration or environmental conditions |
| `SPIKE` | Sudden change >500 ppm/min (SCD41 only) | Investigate sensor or physical event |
| `NO_DATA` | No measurements in 10-min window | Check sensor connectivity |
| `LOW_QUALITY` | LGR quality indicator <95 (LGR only) | Check LGR instrument status |
| `BAD_FIT` | LGR fit flag ≠ 3 (LGR only) | Check LGR spectral fit quality |

### QC Flag Usage

**For filtering valid data:**

```python
# Python example
df_valid = df[df['co2_qc'] == 'OK']
```

**For statistics:**

```python
# Check flagged data percentage
flagged_pct = 100 * (df['co2_qc'] != 'OK').sum() / len(df)
print(f"{flagged_pct:.1f}% of data flagged")
```

## Data Types

### Timestamp Formats

**CSV:** ISO 8601 string
```
2024-09-01 12:00:00
```

**Parquet:** `datetime64[ns]` (nanosecond precision)
```python
pd.Timestamp('2024-09-01 12:00:00')
```

**Timezone:** UTC (no timezone suffix)

---

### Numeric Precision

| Type | Precision | Range | Example |
|------|-----------|-------|---------|
| `float64` | 15-17 decimal digits | ±1.7e308 | `420.523456789` |
| `int64` | Exact integers | ±9.2e18 | `1440` |

**Note:** All numeric columns use `float64` for measurements to handle NaN values.

---

### String Values

| Column Type | Values |
|-------------|--------|
| QC Flags | `'OK'`, `'BELOW_RANGE'`, `'ABOVE_RANGE'`, `'SPIKE'`, `'NO_DATA'`, `'LOW_QUALITY'`, `'BAD_FIT'` |
| LGR Fit Flag | `'3'` (good), `'0'`, `'1'`, `'2'`, `'4'` (various quality levels) |

## Reading Data Examples

### Python (CSV)

```python
import pandas as pd

# Read 10-minute CSV
df = pd.read_csv('CO2_SCT1_2M_10min.csv', parse_dates=['timestamp'])

# Read merged CSV
merged = pd.read_csv('SMEAR_EE_CO2_merged.csv', parse_dates=['timestamp'])

# Filter by date
df_sept = df[(df['timestamp'] >= '2024-09-01') & (df['timestamp'] < '2024-10-01')]
```

### Python (Parquet)

```python
import pandas as pd

# Read Parquet (faster, automatic type inference)
df = pd.read_parquet('CO2_SCT1_2M_2024_09.parquet')

# Selective column reading (columnar format advantage)
df_co2_only = pd.read_parquet(
    'SMEAR_EE_CO2_2024_09_merged.parquet',
    columns=['timestamp', 'lgr_30m_CO2_dry_mean', 'co2_sct1_2m_co2_mean']
)
```

### R (CSV)

```r
library(readr)

# Read CSV
df <- read_csv('CO2_SCT1_2M_10min.csv', col_types = cols(timestamp = col_datetime()))
```

### R (Parquet)

```r
library(arrow)

# Read Parquet
df <- read_parquet('CO2_SCT1_2M_2024_09.parquet')

# Filter with dplyr
library(dplyr)
df_filtered <- df %>%
  filter(co2_qc == 'OK', co2_mean > 400)
```
